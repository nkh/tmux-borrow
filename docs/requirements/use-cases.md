# Power-user use cases

1. Keep a file manager in a home session and borrow it beside the editor without restarting it.
2. Borrow a shared log follower into one project window at a time.
3. Keep a separate file manager instance for each project window.
4. Keep a database console running at home and borrow it when needed.
5. Run multiple REPL instances from one definition with different arguments.
6. Start an ad-hoc monitor with CLI overrides and later return it home.
7. Borrow a build watcher into a debugging window and return it after testing.
8. Open a shared system monitor beside any project.
9. Keep a project-specific debugger with arguments supplied at launch.
10. Restore a project layout containing a file manager, log viewer, and REPL.
11. Clone a layout for another project, reusing shared tools and creating local instances.
12. Restore a layout while preserving ordinary panes already in the window.
13. Select several utilities in fzf and borrow them as a batch.
14. Use a popup to find a utility without remembering its ID.
15. Use `--instance` to select a particular copy in a script.
16. Stop an instance from the manager list even when borrowed elsewhere.
17. Return utilities associated with the current host pane.
18. Let a utility's idle hook reduce its own CPU use at home.
19. Recover a borrowed pane after its home session was deleted.
20. Diagnose an interrupted move without killing an unrecognized pane.
