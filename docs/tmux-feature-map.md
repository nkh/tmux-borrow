# Project functionality mapped to tmux

The manager must not recreate features tmux already provides. This table identifies what tmux supplies directly and what additional project work is required.

| Project capability                 | Corresponding tmux functionality                                                                                | What tmux already does                                                                   | Extra work required by this project?                                                                            |
| ---                                | ---                                                                                                             | ---                                                                                      | ---                                                                                         |
| Create sessions                    | `new-session`                                                                                                   | Creates sessions, detached or attached.                                                  | Yes: policy for home-session assignment, stable manager identity, duplicate-name handling.                                  |
| Create windows                     | `new-window`                                                                                                    | Creates windows within sessions.                                                         | Yes: associate a full-window utility instance with a home location and metadata.                                     |
| Create panes/splits                | `split-window`                                                                                                  | Splits a window and starts a command.                                                    | Yes: borrow an existing running pane rather than launch a new process; optional split argument workflow.                   |
| Move pane between windows/sessions | `join-pane`, `move-pane` (version-dependent command support)                                                    | Moves an existing pane; process remains alive.                                           | Yes: identify resource, track origin/home, handle restoration and metadata.                                                   |
| Move a window between sessions     | `move-window`                                                                                                   | Moves an existing window between sessions.                                               | Yes: utility ownership, home-session tracking, return policy.                                                                  |
| Switch sessions/windows/panes      | `switch-client`, `select-window`, `select-pane`                                                                 | Native navigation and focus.                                                             | No, except selector integration and utility-aware filtering.                                                        |
| Resize panes                       | `resize-pane`                                                                                                   | Resizes panes.                                                                           | No.                                                                                                   |
| Zoom pane                          | `resize-pane -Z`                                                                                                | Toggles zoom.                                                                            | No.                                                                                                   |
| Pane layouts                       | `select-layout`, `next-layout`, `previous-layout`                                                               | Applies built-in layouts to a window.                                                    | Yes: save a named arrangement of manager-owned borrowed resources only; preserve ordinary panes.                            |
| Kill pane/window/session           | `kill-pane`, `kill-window`, `kill-session`                                                                      | Terminates tmux resources.                                                               | Yes: map instance IDs, confirm targets, update metadata, support home/borrowed selectors.                     |
| Pane titles and formats            | `select-pane -T`, format strings                                                                                | Labels panes and exposes metadata for listing.                                           | Yes: stable utility labels, state indicators, selector inventory.                                                      |
| Pane colors                        | `select-pane` style options / pane style options (availability varies by tmux version)                          | Supports pane-specific styling.                                                          | Yes: configured/per-instance borrowed color and restore prior style on return.                                       |
| Popup UI                           | `display-popup` (tmux 3.2+)                                                                                     | Opens a popup running a command.                                                         | Yes: project-specific management UI and minimal shortcut integration.                                                 |
| Key bindings                       | `bind-key`, `unbind-key`                                                                                        | Configures shortcuts and prefix behavior.                                                | Yes: install a small, configurable set of bindings.                                                                           |
| List sessions/windows/panes        | `list-sessions`, `list-windows`, `list-panes`                                                                   | Lists live tmux topology and format fields.                                              | Yes: merge tmux inventory with manager-owned identity and definition metadata.                                             |
| Environment and working directory  | `new-session -c`, `new-window -c`, `split-window -c`, pane formats                                              | Sets or reports working directories and environment.                                     | Yes: config precedence and scope-aware launch defaults.                                                               |
| Save/restore tmux state            | No complete native persistent borrowed-only registry; plugins such as tmux-resurrect provide broad persistence. | tmux itself manages live state, not a project-specific utility registry/layout database. | Yes: borrowed-only layout format, instance state, recovery/reconciliation.                                                    |
| Session grouping                   | `new-session -t` / grouped-session mechanisms                                                                   | Can share windows across sessions.                                                       | Possibly: evaluate whether grouping helps shared utility scope; do not confuse grouped sessions with moving/borrowing. |
| Fuzzy selection                    | Not a core tmux feature; `display-popup` can host an external selector.                                         | Provides popup container and command execution.                                          | Yes: fzf/key-reader UI, inventory generation, action dispatch.                                                             |
| CLI completion                     | Shell completion framework, not tmux core.                                                                      | None for this project's commands.                                                        | Yes: Bash completion for verbs, utility names, IDs, and layouts.                                                      |
| Edit configuration                 | `$EDITOR` is external; tmux has `source-file` for tmux config.                                                  | Can reload tmux configuration.                                                           | Yes: locate and open project config/layouts; validate and reload manager state.                               |
| Setup wizard                       | None.                                                                                                           | None.                                                                                    | Yes.                                                                                          |
| Registered utility definitions     | None.                                                                                                           | Can launch commands in panes/windows.                                                    | Yes: registry, argument schema, defaults, scope, lifecycle policy.                                                         |
| Ad hoc managed utilities           | tmux can launch arbitrary commands.                                                                             | Runs arbitrary commands in sessions/windows/panes.                                       | Yes: auto/manual home assignment, instance IDs, metadata, later selection and return.                                    |
| Per-window vs shared utility scope | Sessions/windows can be created manually.                                                                       | Provides containers but no utility reuse policy.                                         | Yes: scope identity and instance reuse/creation rules.                                                                   |
| Terminate by utility identity      | tmux kills pane/window/session by tmux target.                                                                  | Kills live tmux objects.                                                                 | Yes: resolve stable instance ID and display meaningful target information.                                    |

## Design rule

If the tmux command already performs the operation, call it. The project adds only the identity, policy, metadata, selection, argument resolution, and safety layer needed to make that operation utility-aware.
